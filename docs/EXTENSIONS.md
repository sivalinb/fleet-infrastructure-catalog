# Extension opportunities

| Capability | Acceptance evidence |
| --- | --- |
| Continuous read-only source connectors | Reconnect, pagination, deduplication, and incomplete-snapshot tests |
| Incremental projection updates | Same resolved output as full reconciliation across randomized updates |
| Versioned schema migrations | Upgrade and restore against populated databases |
| Service ownership history | Historical owner and source attribution remain queryable |
| External operational context | Explicit API integration with incident or telemetry systems; unavailable sources remain visible |
| Shared access | Identity-aware authorization, tenant isolation, and authenticated interface access |

These are design directions, not implemented capabilities or delivery commitments.
