Data model

One identity, multiple observations

Raw source records remain separate from the resolved entity. Imports are transactional and replay-safe. Omitted records retain identity and history; freshness is explicit.

Verification

Correctness before scale claims

Tests cover authority, conflicts, missing records, stale sources, import replay, rollback, cycle-safe traversal, source normalization, API access, and Gradio exports. PostgreSQL checks verify reconciliation after restart.

Design considerations

Scaling follows measured bottlenecks

Incremental projections, paginated queries, bounded graph traversal, source checkpoints, and durable ingestion jobs address growth. Preserve snapshot completeness and provenance across every change.

Scope

A standalone catalog foundation
